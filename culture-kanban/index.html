The rules
  • On your turn, choose a task that is not done, then draw a card.
  • Smooth hour (18): move the chosen task one step.
  • Breakthrough (2): move the chosen task straight to Done – or leave it and lift an external block.
  • Dependency (3): the chosen task turns out to need another task first (picked at random, never a blocked task and never one that another task already waits for). It cannot move until that task is done.
  • Takes longer (3): the hour goes into the chosen task, but it does not move.
  • Rework (2): someone wants changes. A started task (the chosen one if it is in progress, otherwise another started task) goes back to Not Started, and the hours already put in are lost. Done tasks are never sent back.
  • Urgent request (2): a new task lands in Not Started. The hour goes to handling it, so the chosen task does not move.
  • External block (2): the chosen task moves to Blocked. It waits for an email, a decision or a delivery from outside the team. The team cannot speed this up: only a Breakthrough lifts the block.
  • Round 2 adds one rule: a WIP limit on In Progress for the whole team. A task that another task is waiting for may always be started, and does not count toward the limit. Players also pull work from the right: on your turn you 1) finish a task in In Progress if you can, otherwise 2) work on a task that another task is waiting for, and only then 3) start a new task.
  • Planning (optional in round 2): the team spends the first round, one turn per player, mapping which tasks depend on which. No cards are drawn. In return 2 of the 3 Dependency cards and 2 of the 3 Takes longer cards become Smooth hours: the team knows what depends on what and how big each task is. Rework stays, since people change their minds anyway. The game is just as long, so the team draws 4 fewer cards.
  • Waste: every hour put into a task that is not done when the game ends. Lean counts it as waste: the time is spent, but nobody gets any value from it.
  • Every task has an owner: the player who started it. When someone else finishes it, that counts as collaboration. In round 1, how willing players are to take over someone else's task can be set: high, medium, or low (only when there is nothing else to do). Their own started tasks they always pick up. In round 2 the pull order decides, whoever started the task.

The deck has 32 cards: 20 that help (18 Smooth hours, 2 Breakthroughs) and 12 mishaps (3 Dependency, 3 Takes longer, 2 Rework, 2 Urgent request, 2 External block). Both rounds draw the same cards in the same order.

In round 1 the players behave like people without kanban habits: they would rather start a new task than take over one that is already in progress (by default 70% of the time). In round 2 they follow the pull order above. The difference between the rounds therefore comes from three things together: the pull order, the WIP limit and, if chosen, planning.
